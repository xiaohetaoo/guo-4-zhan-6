# 过四斩六

> 一款**完全离线、完全免费**的四六级单词记忆 App —— 装上就能用，断网也能背。

---

## 这是什么

把 AIGC 的「生成」环节**前置到开发阶段**，用大模型批量生产词条级助记内容，再固化进安装包；
运行阶段只做本地查询——**零网络、零推理、零延迟**，同时天然规避学习数据外泄。

| 指标 | 数值 |
| :--- | :--- |
| 安装包体积 | **9.06 MB** |
| 词条总数 | **10998** 条（四级 4750 / 六级 6248） |
| 单元切分 | 每单元 **50 词**（四级 95 个单元 / 六级 125 个单元） |
| 网络权限 | **0**（刻意不申请 `INTERNET`） |
| 申请权限 | 仅 `VIBRATE` |
| 例句覆盖 | 99.7%（10968 条真实语料） |
| 联想记忆覆盖 | 100% |

## 功能

- **完全离线**：学习、助记、复习、统计、闯关全程不联网，开飞行模式照常可用。
- **完全免费**：无会员、无内购、无广告。竞品把词根词缀、柯林斯词典、近义词、生词本等逐项收费
  （官方按用量算出的年费合计 581 元），本项目对应功能全部内置。
- **五层内容**：每个单词都有发音（系统离线 TTS，英美双音标）、释义（中文精要 + 多义项 + 英文释义 + 词性）、
  例句（真实语料打分筛选）、词根词缀（前后缀 + 中文含义拆解）、联想记忆（谐音联想 + 形近词辨析 + 词形变化）。
- **SM-2 间隔重复**：按 SuperMemo-2 维护难度因子与连续答对次数，答对后间隔按「1 天 → 6 天 → 上次间隔 × ease」递增，
  答错则重新排队。
- **桌面图标可切换**：设置页可选「默认图标」或「简洁图标（橙底白字大字标）」；
  简洁图标会**自动跟随级别**——四级显示大字「四」，六级显示大字「六」。
- **单词闯关**：选义题 + 听音拼写题，单元关每关 10 题、本级「全词挑战」随机 50 题；连击加分、三星评价，答完即时展示答案与例句。
- **拓展练习**：易混词辨析、真题句子翻译两类专项各 10 题，从「我的」页进入，成绩不计入排行榜（避免与闯关混排）。
- **词库浏览**：按单元列表、按首字母「全词预览」，支持英文单词或中文释义搜索（命中过多时按字母序截断并提示）。
- **排行榜与成就**：每局成绩自动入榜；81 项成就分铜 / 银 / 金三档，徽章用汉字字形 + 配色实现，零图片资源。
- **数据导出与备份**：导出学习记录 / 单词本（CSV）、备份全部数据（JSON）并支持恢复，
  文件写入应用私有外部目录，不申请任何存储权限。

## 从源码构建

**环境要求**

- JDK 17
- Android SDK（compileSdk 34 / targetSdk 34 / minSdk 26）
- Gradle 8.7

**步骤**

```bash
# 1. 配置 SDK 路径
echo "sdk.dir=/path/to/Android/sdk" > local.properties

# 2. 构建 release 包（需自行配置签名；仓库不含签名密钥）
gradle assembleRelease

# 产物：app/build/outputs/apk/release/app-release.apk
```

> 仓库**不包含** `local.properties` 与签名密钥 `cetvocab-release.jks`，请自行生成。
> 未配置签名时可用 `gradle assembleDebug` 构建调试包。

词库以 `app/src/main/assets/words.db`（SQLite，7.61 MB）随包分发，构建期不需要联网。

```

├── app/
│   ├── build.gradle.kts
│   └── src/main/
│       ├── AndroidManifest.xml          # 三个 activity-alias 提供可切换的桌面图标

│       ├── java/com/hdu/cetvocab/
│       │   ├── CetVocabApp.kt           # Application，启动时校正桌面图标
│       │   ├── MainActivity.kt          # 唯一 Activity，onStop 落地图标切换
│       │   ├── data/                    # 词库、用户库、复习算法、备份
│       │   ├── ui/                      # Compose 界面（首页/词库/闯关/我的/设置）
│       │   └── util/                    # 离线 TTS、图标切换器
│       └── res/                         # 主题、图标（含「四」「六」两套简洁图标）
├── tools/
│   ├── build_words_db.py                # 词库构建流水线（50 词/单元）
│   ├── verify_db.py                     # 词库校验
│   └── pack_source.py                   # 源码打包
└── README-构建说明.md
```
